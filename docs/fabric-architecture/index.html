Microsoft Fabric Ingestion Architecture

Follow the USGS and World Bank demo payloads from public APIs through OneLake to the Gold metrics table.

Public APIs

USGS earthquake events and World Bank population data.

Landing

Write the raw JSON and batch manifest to OneLake. Record the attempt in the landing ledger.

Bronze

Store the raw payload with its source path, batch ID, and attempt ID.

Silver

Validate completeness, keys, and values, then publish typed records.

Gold

Publish daily quake counts, maximum magnitude, and annual population metrics.

Configuration

vl_ingestion selects the workspace settings. ops.connection and ops.dataset define the two sources and their extraction settings.

Retry and replay

Run the same batch again to reuse successful Landing payloads. A failed quality check stops that run before Silver or Gold is published.
